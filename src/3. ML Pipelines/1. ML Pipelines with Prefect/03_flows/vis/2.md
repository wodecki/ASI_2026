# 2.py - ETL Pattern with Subflows

```mermaid
flowchart TD
    subgraph MAIN["@flow etl_pipeline()"]
        subgraph EXTRACT["@flow extract_flow()"]
            E1["@task read_csv(products)"]

        subgraph TRANSFORM["@flow transform_flow()"]
            T1["@task merge_data"]
```

## ETL Architecture
```
etl_pipeline (orchestrator)
├── extract_flow
│   ├── @task read_csv(products)
│   └── @task read_csv(sales)
├── transform_flow
│   ├── @task merge_data
│   └── @task add_revenue
└── load_flow
    └── @task save_output
```

## Notes
- Subflows group related tasks
- Each ETL phase is a reusable subflow
- Tasks within subflows for granular tracking
