# 1.py - Basic Subflows

```mermaid
flowchart TD
    subgraph MASTER["@flow master_flow()"]
        subgraph PREP["@flow prepare_data()"]
            P1[Return customer IDs]
        end

        subgraph PROC1["@flow process_customer(1)"]
            C1[Process & return result]
        end

        subgraph PROC2["@flow process_customer(2)"]
            C2[Process & return result]
        end

        subgraph PROC3["@flow process_customer(3)"]
            C3[Process & return result]
        end

        PREP --> PROC1
        PREP --> PROC2
        PREP --> PROC3

        PROC1 --> R[Collect results]
        PROC2 --> R
        PROC3 --> R
    end

    style MASTER fill:#e8f4f8,stroke:#0077b6
    style PREP fill:#caf0f8,stroke:#0077b6
    style PROC1 fill:#ffe8cc,stroke:#ff9f1c
    style PROC2 fill:#ffe8cc,stroke:#ff9f1c
    style PROC3 fill:#ffe8cc,stroke:#ff9f1c
    style R fill:#90e0ef,stroke:#0077b6
```

## Flow Hierarchy
```
master_flow (parent)
├── prepare_data (child)
└── process_customer (child, called 3x)
```

## Notes
- Flows can call other flows (subflows)
- Each subflow tracked independently in Prefect UI
- Parent-child relationships visible in UI
