# 1.py - Basic Tasks and Flows

```mermaid
flowchart TD
    subgraph FLOW["@flow basic_pipeline()"]
        A["@task load_products"] --> C["@task compute_revenue"]
        B["@task load_sales"] --> C
        C --> D[Result]
    end

    CSV1[(products.csv)] --> A
    CSV2[(sales.csv)] --> B

    style FLOW fill:#e8f4f8,stroke:#0077b6
    style A fill:#caf0f8,stroke:#0077b6
    style B fill:#caf0f8,stroke:#0077b6
    style C fill:#caf0f8,stroke:#0077b6
    style D fill:#90e0ef,stroke:#0077b6
```

## Notes
- `@task` decorators enable tracking, retries, caching
- `@flow` orchestrates tasks and provides observability
- Prefect tracks: start time, duration, status, dependencies
